## 极限与连续

极限是微积分的核心概念。ε-δ 定义虽然抽象，但描述了函数值趋近于某个确定值的本质。

### 重要性质
- 极限的唯一性
- 局部有界性
- 夹逼定理

## 导数

导数描述函数的变化率，几何意义是切线斜率。

### 求导法则
1. 幂函数：(x^n)' = nx^(n-1)
2. 和差法则：(u±v)' = u'±v'
3. 乘积法则：(uv)' = u'v + uv'
4. 链式法则：(f(g(x)))' = f'(g(x)) · g'(x)

## 积分

积分是导数的逆运算，定积分表示曲边梯形的面积。

### 基本积分公式
- ∫x^n dx = x^(n+1)/(n+1) + C (n≠-1)
- ∫e^x dx = e^x + C
- ∫sin(x)dx = -cos(x) + C
- ∫cos(x)dx = sin(x) + C
