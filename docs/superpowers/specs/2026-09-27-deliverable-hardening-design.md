# 课程导入与学习功能交付收尾设计

## 目标与边界

在现有本地单用户 Dashboard 上完成截图列出的导入、统计、复习、导出、深色模式与上传体验。沿用现有课程目录和 API，不做账号系统或无关重构。所有显示为事实的数据必须来自课程文件或学习记录，不得模拟。原 PDF、Word、HTML、文本课件继续保存在课程目录，但不嵌入 JSON 导出。

## 实现设计

### 文档导入

统一 PDF、DOCX、HTML、Markdown 与 TXT 的提取结果语义：标题提纲引用有效页或章节序号，来源类型与原始扩展名分别保留；生成的课程说明、预览和资源链接与原文件一致。空文件、损坏文件、超限文件返回明确错误。DOCX 保留 60 秒转换保护。上传使用 XHR 进度，失败后“重试”实际重新上传同一文件；拖放与文件选择共享同一校验路径。确认后文件类型标签、成功提示、阶段顺序应与最终课程一致。上传草稿和临时文件只由一个定时器清理。

### 统计与复习

统计图表以课程和学习记录中的真实日期、完成状态计算；没有数据时显示空态，不伪造每日柱形图或连续天数。连续天数按不同自然日的学习记录计算。复习提醒以可追溯的学习/复习记录为依据，按 1、3、7、30 天形成待复习日期，不把一条记录重复分配给所有阶段；日历显示相关未来提醒并与待复习 API 的口径一致。

### 导出与主题

全量和单课程 JSON 导出包含课程 Markdown 文件及 `sessions/` 内的学习记录，保留目录相对路径；不包含原 PDF/Word 等二进制课件。导出结构清楚标识版本、时间和课程，未知课程返回明确错误。深色模式覆盖现有页面并把选择保存在 localStorage；不支持 `matchMedia` 的环境安全降级。

## 验证与交付

先为缺陷添加会失败的回归测试，再逐项修复。更新 XHR 上传测试，使测试真实模拟 XHR 而不是继续拦截 fetch；为解析、复习去重、统计真实性、导出 sessions、扩展名、重试与错误处理补充测试。运行完整单元/接口测试、浏览器流程测试和构建。仅在验证通过后暂存非 `.md` 代码文件并推送；用户已有及本设计说明等 `.md` 文件均不纳入推送。
