# 多文件创建课程与追加课件验收

日期：2026-10-07。环境：本机 Windows，隔离临时工作区和临时端口。

## 交付行为

- 新建课程支持混合 PDF、DOCX、HTML、Markdown 和 TXT；每批 1–10 个文件，总计不超过 200 MB，原单文件格式与大小限制保留。
- 每份文件独立解析、编辑、自动保存及使用可选 AI 完善，确认后按文件选择顺序合并为一门课。整体课程名称在更新合并预览或确认时保存。
- 课程详情新增“追加课件”。预览后明确确认，新增阶段、笔记摘录、资源和明确日期；已有完成状态、学习记录、个人笔记、错题和复习数据保留。
- 每份来源具有独立 ID、原文件及来源位置。同名文件不会覆盖；PDF 页码仍指向各自原文件，非 PDF 保持估算位置语义。每门课程最多 100 份来源文件。
- 多文件来源参与 ZIP 备份和恢复；恢复为新课程时对应来源链接更新。
- 草稿修订和课程文件哈希检查阻止冲突覆盖。重复确认不重复创建或追加；中断提交可在服务重启时继续验证恢复，无法核对的事务保留并隔离。

## 边界与学习要点

此次未调用付费模型；浏览器验收使用基础草稿，AI 操作沿用每份课件的已有流程。没有新增 OCR，扫描无文字层及加密 PDF 仍不支持。整批草稿不属于课程 ZIP 备份内容。

关键取舍是“每份文件独立草稿，最后一起确认”：它使原文件页码不会因合并而失真，同时可在提交前统一核对所有修订。追加采用原档案版本检查和共享课程写入锁，避免把旧完成状态或笔记重新生成。可继续学习多文件内容去重、版本历史与事务恢复。
